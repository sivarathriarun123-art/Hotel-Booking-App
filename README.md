This is a recreated Flutter source project based on the available APK and the previously described lab-project screens. It is **not the exact original source code recovered from the APK**.

## Features
- Hotel search by name or location
- Check-in and check-out date selection
- Guest count selection
- Hotel list and details
- Booking form with basic validation
- Estimated booking total and confirmation screen
- Booking history placeholder

## Requirements
- Flutter SDK (Dart 3.3 or newer)
- Android Studio or Visual Studio Code with Flutter extension

## Run
```bash
flutter pub get
flutter run
```

## Build an APK
```bash
flutter build apk --release
```
The release APK is usually generated at `build/app/outputs/flutter-apk/app-release.apk`.

## Important limitations
This is a student-project demo. It uses sample hotel data, does not connect to a backend, does not process payments, and does not persist bookings between app launches.
